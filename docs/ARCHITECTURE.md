# Архитектура приложения

Приложение построено как модульный монолит: React-клиент, FastAPI-сервер и PostgreSQL.

## Компоненты

- **Frontend:** React + TypeScript, Vite собирает статические файлы на этапе создания Docker-образа. Nginx отдаёт собранный интерфейс и проксирует `/api/` и `/ws/` на backend. Dev-сервер Vite в рабочем контейнере не запускается.
- **Backend:** `app/main.py` создаёт FastAPI-приложение и подключает отдельные роутеры. `db.py` содержит модели и подключение БД; `schemas.py` — валидацию запросов; `dependencies.py` — авторизацию и права; `realtime.py` — рассылку событий WebSocket; `reports.py` — генерацию еженедельных отчётов.
- **Database:** PostgreSQL хранит пользователей, проекты, роли, колонки, задачи, комментарии и отчёты.

## Потоки данных

1. Клиент отправляет REST-запрос с JWT.
2. Роутер проверяет авторизацию и роль через зависимости, обращается к SQLAlchemy и возвращает JSON.
3. После изменения задачи WebSocket-хаб уведомляет подключённых участников; клиент обновляет доску.
4. APScheduler периодически формирует статистику задач в таблице отчётов.

## Структура backend

```text
app/
  main.py           # создание приложения
  db.py             # ORM и соединение
  schemas.py        # Pydantic-схемы
  dependencies.py   # JWT и права доступа
  auth.py           # регистрация и вход
  projects.py       # проекты, участники, колонки
  tasks.py          # операции с задачами
  comments.py       # комментарии
  report_routes.py  # API отчётов
  reports.py        # фоновая генерация
  realtime.py       # WebSocket-хаб
  ws.py             # WebSocket endpoint
  serializers.py    # сериализация задач
```

## Запуск

```bash
docker compose up --build -d
```

Приложение: http://localhost:5173; Swagger: http://localhost:8000/docs.

Для разработки интерфейса Vite можно запускать отдельно на компьютере командой `npm run dev`, но не как основной процесс рабочего Docker-контейнера.
